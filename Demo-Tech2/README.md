# Clay Pot — Handcrafted Ceramics

A Next.js marketing site for a fictional artisan ceramics brand, matching the reference design.

## Pages
- `/` — Home (hero, archive, philosophy, process, collection, featured, journal, trust)
- `/shop` — Product grid with filters
- `/about` — Story, manifesto, values, team
- `/journal` — Featured essay + category grid
- `/contact` — Info, form, FAQ, studio location

## Getting started
```bash
npm install
npm run dev   # runs on port 3001
```
Open http://localhost:3001

## Stack
- Next.js 14 (App Router)
- Tailwind CSS 3
- Google Fonts: DM Serif Display, Cormorant Garamond, Caveat, Inter
- Images from Unsplash / Pexels / Pinterest (remote patterns in `next.config.mjs`)
