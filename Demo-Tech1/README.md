# Luxe Nails — Next.js

Elegant nail-studio marketing site built with Next.js (App Router) and Tailwind CSS.

## Pages
- `/` — Home (hero, service cards, about, booking)
- `/services` — Services listing with pricing
- `/gallery` — Filterable gallery
- `/about` — Story, team, stats, testimonial
- `/contact` — Contact form, location, hours

## Getting started
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Stack
- Next.js 14 (App Router, JS)
- Tailwind CSS 3
- Google Fonts: Cormorant Garamond, Great Vibes, Inter
- Images from Unsplash (remote patterns configured in `next.config.mjs`)
